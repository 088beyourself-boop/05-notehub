# NoteHub

A React and TypeScript application for searching, creating, and deleting notes.

## Development

1. Install dependencies:

   ```bash
   npm install
   ```

2. Copy `.env.example` to `.env.local` and add your NoteHub access token:

   ```env
   VITE_NOTEHUB_TOKEN=your_token
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

## Checks

```bash
npm run format:check
npm run lint
npm run build
```
